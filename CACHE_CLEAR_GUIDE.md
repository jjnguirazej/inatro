# 🔄 Guia de Atualização - INATRO

## Se você está vendo a versão antiga do site:

### 📱 **iPhone/iPad (Safari/Chrome/Firefox)**
1. Feche completamente o app do navegador:
   - Deslize para cima da parte inferior da tela
   - Encontre o app do navegador
   - Deslize para cima para fechar
2. Abra o Safari:
   - Configurações → Safari → Limpar Histórico e Dados
3. Reabra o site: `inatro-sofala.com`

### 🤖 **Android (Chrome/Firefox)**
1. **Chrome:**
   - Abra o Chrome
   - Toque nos 3 pontos (⋮) no canto superior direito
   - Configurações → Privacidade → Limpar dados de navegação
   - Selecione "Imagens e arquivos em cache"
   - Toque em "Limpar dados"
   
2. **Firefox:**
   - Menu → Configurações → Excluir dados de navegação
   - Marque "Cache" e "Cookies"
   - Toque em "Excluir dados de navegação"

### 💻 **Desktop (Windows/Mac)**
1. **Chrome/Edge:**
   - Pressione: `Ctrl + Shift + Delete` (Windows) ou `Cmd + Shift + Delete` (Mac)
   - Selecione "Imagens e arquivos em cache"
   - Clique em "Limpar dados"
   
2. **Firefox:**
   - Pressione: `Ctrl + Shift + Delete` (Windows) ou `Cmd + Shift + Delete` (Mac)
   - Marque "Cache"
   - Clique em "Limpar agora"

3. **Safari (Mac):**
   - Safari → Preferências → Avançado
   - Ative "Mostrar menu Desenvolver"
   - Desenvolver → Esvaziar Caches
   - Ou pressione: `Cmd + Option + E`

### ⚡ **Método Rápido (Todos os navegadores)**
Ao abrir o site, pressione:
- **Windows:** `Ctrl + F5` ou `Ctrl + Shift + R`
- **Mac:** `Cmd + Shift + R`
- **Mobile:** Puxe a página para baixo para recarregar
